# DGD SNS Bot

学術誌 *Development, Growth & Differentiation (DGD)* の新着論文・最新号情報を自動投稿するボット。

## 機能

- 新しい号が発行されたときに投稿
- 新着論文が公開されたときに投稿
- 追悼記事が掲載されたときは、専用の文面で投稿
- WileyのRSSフィードを利用
- Blueskyに自動投稿し、佐藤（DGDのSNS担当）と桃津さん（JSDBのSNS担当）にメールを送信
- 佐藤がメールの投稿文を使ってDGDのXアカウントへ手動で投稿（Xの自動投稿は現在停止中）

## 現在の投稿フロー

1. GitHub ActionsがWileyのRSSフィードを確認する。
2. 新着論文または新しい号があればBlueskyに投稿し、メールを送信する。
3. 佐藤がメールの投稿文をコピーしてDGDのXアカウントに手動で投稿する。
4. 桃津さんには、JSDBのアカウントからDGDの投稿をBlueskyとXでリポストしてもらうようメールで依頼する。

メールは佐藤と桃津さんの両方に送る。新着論文のメールにはBlueskyの投稿文が含まれる。新しい号のメールには投稿内容に加えて目次も含まれる。メールには桃津さん宛ての挨拶文とリポスト依頼、佐藤の署名が付くため、Xには投稿部分をコピーする。

Xの自動投稿は有料サービスの利用が必要なため、現在は見送っている。将来、自動化を再検討する可能性がある。

## 追悼記事

WileyのRSSで記事区分が `OBITUARY`（または `IN MEMORIAM`、`MEMORIAL`）の場合は、通常の「New article in DGD.」ではなく、区分・題名・執筆者名・DOIをBlueskyへ自動投稿する。同じ内容を含むメールも佐藤と桃津さんに送る。DOIが文字数制限で切れないよう末尾に確保する。

Gurdon先生の追悼記事（DOI: `10.1111/dgd.70039`）は手動投稿済みとして扱い、重複投稿を防ぐ。本文の抜粋と画像は自動では追加しない。RSSで別の区分が付いた追悼記事は通常の新着論文として扱われるため、掲載時には記事区分を確認する。

## GitHub Secrets の設定

| シークレット名 | 内容 |
|---|---|
| `BSKY_USERNAME` | BlueskyのユーザーID |
| `BSKY_PASSWORD` | Blueskyのパスワード |
| `MAIL_USER` | 送信元Gmailアドレス |
| `MAIL_PASS` | Gmailの**アプリパスワード**（通常のパスワードとは別） |
| `MAIL_FROM` | 送信元メールアドレス |
| `MAIL_TO` | 送信先メールアドレス |

### アプリパスワードについて

- `MAIL_PASS` には通常のGmailパスワードではなく、**アプリパスワード**を設定すること
- アプリパスワードは https://myaccount.google.com/apppasswords で発行する（2段階認証が必要）
- **Gmailのパスワードを変更すると、アプリパスワードはすべて無効化される**。パスワード変更後は必ずアプリパスワードを再発行してGitHub Secretsを更新すること

## 運用

GitHub Actionsにより6時間ごとに自動実行される。手動実行も可能。

実行後は `posted.json` に投稿済みDOIが記録され、重複投稿を防ぐ。

## 管理者

DGD誌のSNS担当者が管理。
